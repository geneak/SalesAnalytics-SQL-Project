# Power BI Sales Analytics Dashboard

## Project Overview
An interactive Sales Analytics Dashboard built using Power BI and SQL Server.

## Key Features
- Total Revenue and Total Profit
- Profit Margin Analysis
- Revenue Trends by Year
- Average Order Value by Product
- Revenue by State
- Product Performance and Ranking
- Interactive Year, Month, Product and Payment Method slicers

## Technologies
- Microsoft Power BI
- SQL Server
- DAX
- Power Query
- Data Modeling
- Data Visualization
